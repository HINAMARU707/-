# 시라츠키 학원 고등부 공식 홈페이지 v1

## 사용 방법
1. 압축을 풉니다.
2. VS Code에서 폴더를 엽니다.
3. index.html을 브라우저로 열면 됩니다.
   - Live Server 확장 프로그램을 사용하면 더 안정적으로 확인할 수 있습니다.

## 파일 구성
- index.html : 홈페이지 구조
- style.css : 디자인
- script.js : 페이지 전환 / 학생증 발급 / PNG 저장 기능
- images : 기존 시라츠키 학원 사진 에셋

## 적용한 고정 규칙
- 학교명: 시라츠키 학원 고등부 / 白月学園高等部 / SHIRATSUKI ACADEMY HIGH SCHOOL
- 슬로건: 지성과 품격, 미래를 여는 교육
- 교육 이념: 지성 · 품격 · 책임
- 기존 사진 에셋만 사용
- 화이트 / 네이비 / 스카이블루 / 금색 소량
- 초여름, 맑은 하늘, 현대식 사립학교 분위기
